## 為什麼要學終端機

雲端上的虛擬機沒有螢幕和滑鼠，你會透過網路連進去，用打字的方式下指令。AWS 和 GCP 的命令列工具也是在終端機裡執行。會用終端機，才有辦法做後面每一個實作。

終端機會顯示一行**提示字元**，等你輸入指令：

```bash
learner@cloud:~$
```

這行的意思是：使用者 `learner` 在名為 `cloud` 的機器上，目前位置是 `~`。輸入指令後按 Enter 執行。

## 目錄與路徑

Linux 的檔案放在一層一層的**目錄**裡，最上層是根目錄 `/`。描述位置的寫法叫**路徑**，有兩種：

| 寫法 | 例子 | 意思 |
|---|---|---|
| 絕對路徑 | `/home/learner/notes.txt` | 從根目錄 `/` 開始寫，在哪裡執行都指向同一個地方 |
| 相對路徑 | `projects/notes.txt` | 從你目前所在的目錄開始算 |

有幾個常用的簡寫：

- `~`：你的家目錄，在這裡是 `/home/learner`。
- `.`：目前所在的目錄。
- `..`：上一層目錄。

## 看看自己在哪裡

```bash
# 顯示目前所在的目錄
pwd

# 列出目前目錄裡有什麼
ls

# 列出詳細資訊，並包含隱藏檔
ls -la

# 移動到 projects 目錄
cd projects

# 回到上一層
cd ..

# 不加參數，直接回家目錄
cd
```

<Callout title="隱藏檔">
名稱以 `.` 開頭的檔案是隱藏檔，`ls` 預設不顯示，要加 `-a` 才看得到。很多設定檔都是隱藏檔。
</Callout>

## 建立目錄與檔案

```bash
# 建立目錄
mkdir projects

# 一次建立多層目錄
mkdir -p projects/web/assets

# 建立一個空檔案
touch notes.txt

# 把文字寫進檔案（會覆蓋原本的內容）
echo "hello" > notes.txt

# 把文字加到檔案最後面
echo "world" >> notes.txt

# 顯示檔案內容
cat notes.txt
```

`>` 和 `>>` 叫做**輸出重新導向**，會把原本要顯示在畫面上的文字改存進檔案。兩者只差一個符號，效果差很多：`>` 會把原本的內容整個蓋掉。

## 複製、搬移與刪除

```bash
# 複製檔案
cp notes.txt backup.txt

# 複製檔案到另一個目錄
cp notes.txt projects/

# 複製整個目錄要加 -r
cp -r projects projects-backup

# 搬移檔案
mv backup.txt projects/

# mv 也用來改名
mv notes.txt todo.txt

# 刪除檔案
rm todo.txt

# 刪除目錄和裡面所有東西
rm -r projects-backup
```

<Callout title="刪除沒有資源回收筒">
`rm` 刪掉的東西救不回來，也不會再跟你確認。執行 `rm -r` 之前，先用 `pwd` 和 `ls` 確認自己在哪裡、要刪的是什麼。
</Callout>

## 幾個省力的技巧

- **Tab 鍵自動補完**：打檔名的前幾個字再按 Tab，終端機會幫你補完。
- **上下方向鍵**：叫出之前執行過的指令。
- **`&&` 串接指令**：`mkdir demo && cd demo` 會在建立成功後才進入目錄。

## 重點整理

- 路徑分絕對和相對；`~` 是家目錄，`.` 是目前目錄，`..` 是上一層。
- `pwd`、`ls`、`cd` 用來確認位置和移動。
- `mkdir`、`touch`、`echo >` 用來建立目錄和檔案，`cat` 用來看內容。
- `cp` 複製、`mv` 搬移或改名、`rm` 刪除；處理目錄時 `cp` 和 `rm` 要加 `-r`。
- `>` 會覆蓋檔案，`>>` 是加在後面；`rm` 沒有後悔藥。
